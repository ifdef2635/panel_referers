Интеграции

1. Модуль для бота

Бот отправляет события в панель POST-запросами, а панель складывает их в свою базу и считает по ним метрики. Читать базу бота панели не нужно.

  • events_api.md — описание API: формат событий, поля, ответы, ретраи.
  • kago_emitter.py — модуль для кода бота: неблокирующая очередь, отправка пачками, повторы.
  • remnashop_sync.py — выгрузка истории из БД Remnashop (backfill). С флагом --watch досылает изменения каждые N секунд, поэтому может работать и без правок в коде бота.

Для кабинетов партнёров в событии user.registered нужны поля referrer_id (кто пригласил) и/или source (рекламная ссылка). Поля name, username и telegram_id нужны, чтобы находить пользователей в панели.
