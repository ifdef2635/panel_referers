# Referral Panel для Remnashop

Веб-панель статистики по приведённым пользователям для бота [Remnashop](https://github.com/snoups/remnashop).

- **Партнёры** («рефералодатели») входят по логину и паролю и видят статистику только своих пользователей: регистрации, триалы, покупки, конверсию, выручку, графики, список пользователей и своё вознаграждение.
- **Администратор** видит общую статистику магазина: все пользователи, выручка по валютам, платёжные системы, тарифы, источники трафика (органика / рефералы / рекламные ссылки), рейтинг партнёров, а также управляет партнёрами и учитывает выдачу вознаграждений.

Данные читаются напрямую из PostgreSQL Remnashop **только на чтение**. Бот ничего не замечает, ставить в него ничего не нужно.

## Как считается

**Кто приведён партнёром.** Партнёру привязываются источники из Remnashop:
- *реферер* — пользователь бота, чьей реферальной ссылкой пользуется партнёр (таблица `referrals`); можно включить учёт 2-го уровня;
- *рекламная ссылка* — ссылка из раздела рекламных ссылок Remnashop (`ad_links`).

Один источник принадлежит только одному партнёру, поэтому пользователи не считаются дважды.

**Покупка** — транзакция в статусе `COMPLETED`, не тестовая, с суммой больше 0. Бесплатные (100% скидка), отменённые и возвращённые платежи не учитываются.

**Вознаграждение** — дни подписки: по умолчанию **3 дня за каждого приведённого пользователя, который купил подписку** (один раз на человека, по первой оплате). Ставка меняется в «Настройках» глобально или индивидуально у партнёра. Панель показывает *начислено / выдано / к выдаче*. Сами дни администратор начисляет партнёру в боте, после чего отмечает выдачу в панели. Если платёж вернули, начисление за этого пользователя пропадает.

## Установка на Ubuntu (22.04 / 24.04)

На сервере, где запущен Remnashop:

```bash
git clone https://github.com/ifdef2635/panel_referers.git
cd panel_referers
sudo bash deploy/install.sh
```

Скрипт спросит домен, e-mail для Let's Encrypt, название панели и логин админа, а потом сделает всё сам:

1. установит python3-venv, nginx, certbot;
2. найдёт контейнер `remnashop-db` и создаст в нём роль `panel_ro`: только `SELECT`, а из таблицы `users` только безопасные колонки, без e-mail и хэшей паролей;
3. развернёт код в `/opt/referral-panel`, создаст venv, конфиг `/etc/referral-panel/panel.env` и данные в `/var/lib/referral-panel`;
4. настроит systemd-службу `referral-panel` (uvicorn на 127.0.0.1:8090 с изоляцией), nginx и HTTPS;
5. включит ежедневный бэкап базы панели (хранится 14 копий);
6. выведет адрес панели, логин и сгенерированный пароль администратора.

Без вопросов:

```bash
sudo DOMAIN=stats.example.com LE_EMAIL=me@example.com ASSUME_YES=1 bash deploy/install.sh
```

Если БД Remnashop на другом сервере, передайте строку подключения: `REMNASHOP_DSN=postgresql://user:pass@host:port/remnashop`.

**Обновление:** `git pull && sudo bash deploy/install.sh`. Настройки, партнёры и выдачи сохраняются.

**Управление:**

```bash
sudo refpanel list                      # аккаунты
sudo refpanel create-admin LOGIN        # новый админ
sudo refpanel set-password LOGIN        # сброс пароля
sudo refpanel check-db                  # проверить доступ к Remnashop
journalctl -u referral-panel -f         # логи
```

## Работа с панелью

1. **Рефереры** — список пользователей бота с наибольшим числом приглашённых. Кнопка «Сделать партнёром» создаёт аккаунт и сразу привязывает реферера.
2. **Партнёры → партнёр → Настройки** — привязка рефереров (по Telegram ID, @username или реф. коду) и рекламных ссылок, ставка в днях, 2-й уровень, показ контактов пользователей партнёру, смена пароля, отключение доступа.
3. **Выдачи** — у кого сколько дней к выдаче и журнал всех выдач.
4. Логин и пароль передайте партнёру, он входит на тот же адрес.

## Разработка

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # укажите REMNASHOP_DSN
uvicorn app.main:app --reload
```

Тесты нужно запускать на PostgreSQL со схемой из `tests/remnashop_schema.sql` (база будет очищена):

```bash
pip install pytest httpx
TEST_REMNASHOP_DSN=postgresql://user:pass@127.0.0.1/remnashop_test pytest
```

Совместимость: схема Remnashop после миграции `0026` (внешние ключи по `users.id`), проверено на актуальной версии (миграция `0040`).
